# Create: Envelope compat

This simple mod provides compatibility between Create and Envelope package systems.

Currenly the only supported platform is Neoforge.

## Contents

### Postage stamp
<img height="200" alt="image" src="https://github.com/user-attachments/assets/131db82b-cf8a-4cf6-862b-4bd5303be80b" />

Use this item in the deployer to automatically convert addressed Create packages to the Envelope version. If there are more items in the Create package that could fit into the Envelope one, those items will overflow onto the belt.

### Accessing package contents
Envelope packages processed by the mechanical saw will expell their contents, and give you the address tag + the paper box back.
